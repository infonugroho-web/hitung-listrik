Kebijakan Privasi

Hitung Listrik Rumah adalah alat hitung independen, bukan aplikasi atau layanan resmi PLN. Berlaku sejak 24 November 2026.

Data yang kami kumpulkan

Tidak ada. Aplikasi ini tidak punya server, tidak memakai akun, tidak memasang iklan atau pelacak, dan tidak mengirim data apa pun ke kami atau pihak lain.

Data yang tersimpan di perangkatmu

Pilihan daya, kota/kabupaten, jumlah hari, dan daftar alat listrik yang kamu isi disimpan di penyimpanan lokal browser (localStorage) di perangkatmu sendiri, supaya tidak perlu diisi ulang. Kamu bisa menghapusnya kapan saja lewat tombol "Kosongkan" di aplikasi atau dengan menghapus data situs di browser.

ID pelanggan

Jika kamu mengisi ID pelanggan, hanya 5 digit awal (kode unit) yang dicocokkan dengan daftar di dalam aplikasi, di perangkatmu sendiri. ID pelanggan tidak disimpan dan tidak dikirim ke mana pun, dan aplikasi ini tidak terhubung ke sistem PLN.

Layanan pihak ketiga

Aplikasi memuat huruf (font) dari Google Fonts. Saat itu, browser-mu menghubungi server Google seperti saat membuka situs web biasa.
